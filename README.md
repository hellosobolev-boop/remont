# КВАРТИРА — frontend reference

Локальная статически генерируемая reference-версия сайта компании по ремонту, дизайну, меблировке и комплектации квартир в Москве.

## Запуск

```powershell
npm install
npm run build
npm run start
```

После сборки сайт доступен на `http://localhost:3000`. Локальный сервер отдаёт брендированную страницу с реальным HTTP 404 для неизвестных URL.

## Проверки

```powershell
npm run lint
npm run test:qa
npm audit
```

## Важная граница

Изображения в `public/images` сгенерированы как временная арт-дирекция. Кейсы, цены, сроки, гарантии, команда, отзывы, контакты и реквизиты не выдуманы: отсутствующие значения помечены `ДАННЫЕ ОТ БИЗНЕСА`. Формы работают как локальный UX-прототип и не отправляют данные наружу.

Production-деплой не выполнялся. WordPress/Elementor-архитектура описана в `WORDPRESS_ELEMENTOR_MAPPING.md`.
